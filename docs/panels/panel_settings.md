# Panel Settings

The brightness labels and percentages follow the device `text` color, while the brightness icons use `component_active`. Both therefore remain legible and visually consistent when the Device Colors palette uses a light background. The slider handle and track already follow the theme.

## About

The settings panel provides on-device settings for the display:

- Full brightness
- Dimmed brightness

While the panel is open, auto-dimming is turned off; it is restored when you leave.

**This panel is a system panel: it cannot be added or edited.**
