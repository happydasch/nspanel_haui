# Icons Cheatsheet

Every Material Design icon the display fonts carry. In an item's **Icon** field, use the name
as `mdi:<name>`, for example `mdi:lightbulb`; the cheatsheet also copies the raw codepoint,
which is what a font that is edited by hand needs. Finding an icon on
[Pictogrammers](https://pictogrammers.com/library/mdi/) and extending the set is described in
[Design guidelines](../develop/design.md).
