# Panel Blank

<img src="../../assets/screens/landscape/sys_blank.png" alt="blank panel, landscape" width="300" height="213"> <img src="../../assets/screens/portrait/sys_blank.png" alt="blank panel, portrait" width="142" height="213">

The Blank panel shows nothing. Add it to the [idle panels](../editor/device.md#home-idle) when you want an empty screen instead of a screensaver. The display itself keeps running as usual.

This is a built-in panel. You cannot add or change it.
