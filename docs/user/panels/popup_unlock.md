# Popup Unlock

## About

The unlock popup asks for a PIN before a protected panel opens.

## How to use it

In the panel editor, enter a number in the **Panel pin** field of any panel. From then on the panel asks for this PIN before it opens.

## What it shows

- The title of the locked panel, or **Unlock** when it has none.
- A keypad.
- An **Unlock** button. It becomes active when the PIN is correct.

The popup has the header buttons of the panel it protects, so you can move on without unlocking:

| Locked panel | Header buttons |
|--------------|----------------|
| A panel in the navigation | Previous, home and next |
| A stacked panel | Up, home and close |

Closing the popup never opens the locked panel. In front of a locked navigation panel, closing goes to the home panel. See [Stacked Panels and Popups](../configuration/panels.md#stacked-panels-and-popups).
